# 030-lc322-coin-change

## 题目信息

- 来源：LeetCode 322 Coin Change
- 链接：https://leetcode.cn/problems/coin-change/
- 类型：完全背包 DP
- 难度：中等
- 状态：LeetCode 已通过

## 题意

给定几种硬币面额和一个总金额 `amount`，求凑成这个金额所需的最少硬币数。

如果无法凑出 `amount`，返回 `-1`。

## 思路提示

这题和 416 都属于背包 DP，但是有一个关键区别：

- 416：每个数只能用一次，是 0/1 背包。
- 322：每种硬币可以用无限次，是完全背包。

可以先想：

- `dp[j]` 表示凑出金额 `j` 需要的最少硬币数。
- `dp[0] = 0`，凑出 0 元不需要硬币。
- 如果先凑出 `j - coin`，再加一枚 `coin`，就可以凑出 `j`。
- 所以可以尝试更新：`dp[j] = min(dp[j], dp[j - coin] + 1)`。

## 关键边界

- `amount = 0`。
- 没有任何组合能凑出 `amount`。
- 硬币面额大于 `amount`。
- 需要重复使用同一种硬币。

## 错误记录

- 一开始容易沿用 416 的写法，从大到小遍历 `j`。这题硬币可以重复使用，所以要从小到大遍历。
- `dp` 数组不能只初始化 `dp[0]`，其他位置要先设成一个不可能的较大值，比如 `amount + 1`。
- 最后如果 `dp[amount]` 仍然是 `amount + 1`，说明凑不出来，要返回 `-1`。

## 复杂度

- 时间复杂度：O(coinsSize * amount)。
- 空间复杂度：O(amount)。

## 本地输入格式

```text
n
coins[0] coins[1] ... coins[n-1]
amount
```

样例：

```text
3
1 2 5
11
```

正确输出应该是：

```text
3
```
