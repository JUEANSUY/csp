## 题意

要爬到第 `n` 阶楼梯，每次可以爬 1 阶或 2 阶，求一共有多少种不同的爬法。

例如 `n = 3` 时，有三种：

```text
1 + 1 + 1
1 + 2
2 + 1
```

所以答案是 `3`。

## 我的思路

使用动态规划。

设：

```text
dp[i] = 爬到第 i 阶的方法数
```

到第 `i` 阶的最后一步只有两种可能：

- 从第 `i - 1` 阶爬 1 阶上来。
- 从第 `i - 2` 阶爬 2 阶上来。

所以：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

初始值：

```text
dp[1] = 1
dp[2] = 2
```

## 关键边界

- `n = 1`：答案是 `1`。
- `n = 2`：答案是 `2`。
- 较大的 `n`：按递推式继续计算。

## 滚动变量优化

最开始可以使用 `dp` 数组，容易理解。

因为每次只需要前两个状态，所以最终优化成两个变量：

```text
a = dp[i - 2]
b = dp[i - 1]
current = a + b
```

最终代码使用：

```c
int a = 1;
int b = 2;

for (int i = 3; i <= n; i++) {
    int c = a + b;
    a = b;
    b = c;
}
```

这样空间复杂度从 O(n) 降到 O(1)。

- 空间复杂度：O(1)
