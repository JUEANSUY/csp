# 016-lc415-add-strings

## 题目信息

- 来源：LeetCode 415 Add Strings
- 链接：https://leetcode.cn/problems/add-strings/
- 类型：字符串模拟
- 难度：简单
- 状态：LeetCode 已通过

## 题意

给两个非负整数字符串 `num1` 和 `num2`，返回它们相加后的字符串。

不能直接把整个字符串转成整数，因为字符串可能非常长，会超过 `int` 或 `long long` 的范围。

## 我的思路

把小学竖式加法搬到代码里：

1. 用 `i` 指向 `num1` 最后一位，用 `j` 指向 `num2` 最后一位。
2. 每次取当前位数字，如果某个字符串已经没位了，就当作 `0`。
3. 当前位相加时加上进位 `carry`。
4. 当前结果位是 `sum % 10`。
5. 新进位是 `sum / 10`。
6. 因为是从个位开始算，结果先反着放进 `result`。
7. 加完后给字符串补上 `'\0'`，再把 `result` 反转。

字符和数字之间的转换：

```c
int x = num1[i] - '0';
result[k] = sum % 10 + '0';
```

## 关键边界

- 两个数字长度不同，例如 `11 + 123`。
- 最后还有进位，例如 `999 + 1`。
- 其中一个数字是 `0`。
- 两个数字都是 `0`。
- 数字很长，不能转成整数。

## 错误记录

- C 语言标准库里没有 `max` 函数，要求最大长度时可以写 `len1 > len2 ? len1 : len2`。
- `strrev` 不是标准 C 函数，LeetCode 环境不一定支持，最好自己写双指针反转。
- LeetCode 报 `invalid storage class for function '__LC_get_cpu_time'` 时，通常是前面少了 `}`，导致隐藏测试代码被编译器认为还在自己的函数内部。

## 复杂度

- 时间复杂度：`O(max(n, m))`。
- 空间复杂度：`O(max(n, m))`，返回结果字符串需要额外空间。

## 本地输入格式

```text
num1
num2
```

样例：

```text
11
123
```

正确输出应该是：

```text
134
```
