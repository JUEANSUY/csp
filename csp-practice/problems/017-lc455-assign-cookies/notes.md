# 017-lc455-assign-cookies

## 题目信息

- 来源：LeetCode 455 Assign Cookies
- 链接：https://leetcode.cn/problems/assign-cookies/
- 类型：贪心 / 排序
- 难度：简单
- 状态：LeetCode 已通过

## 题意

有一组孩子的胃口值 `g`，还有一组饼干尺寸 `s`。

如果某块饼干尺寸 `s[j] >= g[i]`，就可以满足第 `i` 个孩子。

每块饼干最多只能分给一个孩子，问最多能满足多少个孩子。

## 我的思路

先把孩子胃口和饼干尺寸都从小到大排序。

然后用两个指针：

- `x` 指向当前还没满足的最小胃口孩子。
- `y` 指向当前还没使用的最小饼干。

如果 `s[y] >= g[x]`，说明这块饼干可以满足当前孩子，就让 `count++`，两个指针都往后走。

如果 `s[y] < g[x]`，说明这块饼干连当前最小胃口的孩子都满足不了，也不可能满足后面的孩子，所以只移动饼干指针 `y++`。

## 贪心点

这题的贪心策略是：

```text
用当前最小能用的饼干，优先满足当前胃口最小的孩子。
```

这样不会浪费大饼干，大饼干可以留给更难满足的孩子。

## 关键边界

- 饼干数量为 0。
- 孩子数量为 0。
- 所有饼干都太小。
- 所有孩子都能被满足。
- `g` 和 `s` 原本是乱序的，需要先排序。

## 错误记录

- `count` 要初始化成 `0`，不能只写 `int count;`。
- 匹配循环条件要用 `x < gSize && y < sSize`，否则可能访问越界。
- 手写双重循环排序是 `O(n^2)`，数据大时会超时。
- C 语言中可以用标准库 `qsort` 排序，比较函数要单独写。

## 复杂度

- 时间复杂度：`O(gSize log gSize + sSize log sSize)`，主要来自排序。
- 空间复杂度：`O(1)`，不额外开数组。

## 本地输入格式

```text
gSize
g[0] g[1] ... g[gSize-1]
sSize
s[0] s[1] ... s[sSize-1]
```

样例：

```text
3
1 2 3
2
1 1
```

正确输出应该是：

```text
1
```
