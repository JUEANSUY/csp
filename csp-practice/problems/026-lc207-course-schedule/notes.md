# 026-lc207-course-schedule

## 题目信息

- 来源：LeetCode 207 Course Schedule
- 链接：https://leetcode.cn/problems/course-schedule/
- 类型：拓扑排序 / 图
- 难度：中等
- 状态：LeetCode 已通过

## 题意

一共有 `numCourses` 门课，编号从 `0` 到 `numCourses - 1`。

`prerequisites[i] = [a, b]` 表示：想学课程 `a`，必须先学课程 `b`。

问是否可以完成所有课程。

## 我的思路

把课程依赖看成有向图。

如果：

```text
[a, b]
```

意思是：

```text
b -> a
```

也就是先学 `b`，再学 `a`。

使用拓扑排序 BFS：

1. 建图：`graph[b]` 里存放学完 `b` 后可以学习的课程。
2. 统计入度：`indegree[a]++`，表示课程 `a` 多了一个前置要求。
3. 把所有入度为 `0` 的课程入队，它们可以一开始就学。
4. 不断从队列里取出课程，表示学完这门课，`learned++`。
5. 学完一门课后，它指向的后续课程入度都减 `1`。
6. 如果某门后续课程入度变成 `0`，说明它的前置课程都学完了，可以入队。
7. 最后如果 `learned == numCourses`，说明能学完所有课程；否则说明有环。

## 关键理解

可以把过程理解成分批学课：

```text
第一批：一开始没有前置课程的课。
第二批：学完第一批后，前置课程都满足的课。
第三批：继续解锁出来的课。
```

注意不是“只有一个前置的课程入队”，而是：

```text
入度变成 0 的课程入队。
```

如果一门课有多个前置课程，必须等所有前置都学完，入度才会变成 `0`。

## 关键边界

- 没有任何先修关系，所有课程都能完成。
- 两门课互相依赖，不能完成。
- 有一部分课程形成环，不能完成。
- 多个课程同时入度为 `0`。

## 错误记录

- `[a, b]` 的方向是 `b -> a`，不要建反。
- `graph[b][graphSize[b]] = a;` 是赋值，要用 `=`，不是 `==`。
- 队列里放的是当前可以学习的课程。
- `learned` 表示已经成功学完的课程数量。

## 复杂度

- 时间复杂度：当前二维邻接表写法约为 `O(numCourses + prerequisitesSize)`，建图和 BFS 都只按边处理。
- 空间复杂度：`O(numCourses^2)`，因为当前用 `graph[MAXN][MAXN]` 存邻接表；后续可优化成更紧凑的边表。

## 本地输入格式

```text
numCourses prerequisitesSize
a0 b0
a1 b1
...
```

样例：

```text
2 1
1 0
```

正确输出应该是：

```text
true
```
