# 018-lc746-min-cost-climbing-stairs

## 题目信息

- 来源：LeetCode 746 Min Cost Climbing Stairs
- 链接：https://leetcode.cn/problems/min-cost-climbing-stairs/
- 类型：动态规划
- 难度：简单
- 状态：LeetCode 已通过

## 题意

给一个数组 `cost`，`cost[i]` 表示踩到第 `i` 个台阶要花多少钱。

每次可以爬 1 个或 2 个台阶，可以从下标 `0` 或下标 `1` 开始，求到达楼顶的最小花费。

注意：楼顶的位置可以理解成 `costSize`，它不在数组里，也不需要花费。

## 我的思路

使用动态规划。

当前代码里的定义是：

```text
dp[i] 表示到达位置 i 之前，已经付过的最小花费。
```

所以：

```c
dp[0] = 0;
dp[1] = 0;
```

这不是说踩到 0 或 1 不花钱，而是因为可以从 0 或 1 开始；费用在“从某个台阶往上跳”时计算。

到达位置 `i` 有两种方式：

1. 从 `i - 1` 跳上来，需要付 `cost[i - 1]`。
2. 从 `i - 2` 跳上来，需要付 `cost[i - 2]`。

所以：

```c
dp[i] = min(dp[i - 1] + cost[i - 1],
            dp[i - 2] + cost[i - 2]);
```

最终答案是：

```c
dp[costSize]
```

## 关键理解

不能只比较 `cost[i - 1]` 和 `cost[i - 2]` 谁小。

要比较的是：

```text
到达 i - 1 的累计花费 + cost[i - 1]
到达 i - 2 的累计花费 + cost[i - 2]
```

某个台阶本身便宜，不代表走到它的总花费一定便宜。

## 关键边界

- `costSize = 2`。
- 可以从 0 开始，也可以从 1 开始。
- 最后一跳可以从倒数第 1 个台阶或倒数第 2 个台阶跳到楼顶。
- 楼顶本身没有花费，不能访问 `cost[costSize]`。

## 错误记录

- 不能访问 `cost[costSize]`，这是数组越界。
- 三目运算取最小值应该写 `a < b ? a : b`。
- 不能用固定 `i--` 加局部最小来模拟路径，动态规划要保存累计最优。

## 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`，当前使用了 `dp` 数组；之后可以优化成 `O(1)`。

## 本地输入格式

```text
n
cost[0] cost[1] ... cost[n-1]
```

样例：

```text
3
10 15 20
```

正确输出应该是：

```text
15
```
