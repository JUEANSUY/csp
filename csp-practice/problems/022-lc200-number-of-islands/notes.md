# 022-lc200-number-of-islands

## 题目信息

- 来源：LeetCode 200 Number of Islands
- 链接：https://leetcode.cn/problems/number-of-islands/
- 类型：DFS / BFS
- 难度：中等
- 状态：LeetCode 已通过

## 题意

给一个由 `'1'` 和 `'0'` 组成的二维网格。

- `'1'` 表示陆地。
- `'0'` 表示水。

上下左右相邻的陆地连在一起，算作同一个岛屿。问一共有多少个岛屿。

## 我的思路

这题本质是找二维网格中的连通块。

从左到右、从上到下扫描整个网格：

1. 如果遇到 `'0'`，直接跳过。
2. 如果遇到 `'1'`，说明发现了一个新的岛屿，`count++`。
3. 从这个位置开始 DFS，把和它上下左右相连的所有 `'1'` 都改成 `'0'`。

把访问过的陆地改成水以后，后面扫描时就不会重复计算同一个岛屿。

DFS 的核心逻辑：

```text
如果越界，返回。
如果当前位置不是 '1'，返回。
把当前位置改成 '0'。
继续搜索上、下、左、右。
```

## 关键边界

- 全是水。
- 全是陆地。
- 只有一行。
- 只有一列。
- 多个岛屿互不相连。
- 只能上下左右连通，斜着相邻不算同一个岛。

## 错误记录

- 判断字符时要写 `grid[i][j] == '1'`，不能写成 `grid[i][j] = '1'`。
- `gridColSize` 是每一行列数的数组，循环时要用 `gridColSize[i]`。
- 本地使用全局 `rows` / `cols` 时，LeetCode 不会自动给它们赋值；要在 `numIslands` 开头根据参数设置。
- 当前递归 DFS 可能 runtime 排名不高，但算法复杂度已经是 `O(m * n)`，每个格子最多访问一次。

## 复杂度

- 时间复杂度：`O(m * n)`。
- 空间复杂度：`O(m * n)`，最坏情况下递归栈可能包含很多陆地格子。

## 优化方向

如果想减少递归函数调用的常数开销，可以之后尝试 BFS 或迭代 DFS。

不过当前阶段重点是理解：

```text
发现一个岛屿 -> DFS/BFS 标记整座岛 -> 继续扫描
```

## 本地输入格式

```text
rows cols
grid[0]
grid[1]
...
grid[rows-1]
```

样例：

```text
4 5
11110
11010
11000
00000
```

正确输出应该是：

```text
1
```
