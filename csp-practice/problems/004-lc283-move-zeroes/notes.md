## 题意

给定一个数组 `nums`，把数组中的所有 `0` 移动到末尾，同时保持非零元素的相对顺序不变。要求原地修改数组。

## 我的思路

使用两趟保序写法：

- 用 `j` 表示下一个非零元素应该写入的位置。
- 第一趟从左到右遍历数组。
- 如果 `nums[i] != 0`，就把它写到 `nums[j]`，然后 `j++`。
- 第一趟结束后，数组前 `j` 个位置已经是所有非零元素。
- 第二趟从 `j` 到 `numsSize - 1`，把剩余位置全部填成 `0`。

这个写法和第 27 题很像，本质都是把“要保留的元素”收集到数组前面。

## 另一种解法

也可以使用一趟交换写法：

```c
void moveZeroes(int *nums, int numsSize) {
    int j = 0;

    for (int i = 0; i < numsSize; i++) {
        if (nums[i] != 0) {
            int temp = nums[i];
            nums[i] = nums[j];
            nums[j] = temp;
            j++;
        }
    }
}
```

这个写法中，`j` 表示下一个非零元素应该放的位置。遇到非零元素时，把它和 `nums[j]` 交换。

注意：这题要求保持非零元素的相对顺序，所以不能使用“把 0 和末尾元素交换”的做法，那样会破坏顺序。

## 关键边界

- 数组中没有 `0`：数组保持不变。
- 数组中全是 `0`：数组保持全 0。
- `0` 在开头：非零元素能正确前移。
- `0` 在结尾：数组保持正确。
- `0` 连续出现多次：所有 0 都移动到末尾。
- 单元素数组：能正确处理。
