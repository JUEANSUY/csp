# 021-lc198-house-robber

## 题目信息

- 来源：LeetCode 198 House Robber
- 链接：https://leetcode.cn/problems/house-robber/
- 类型：动态规划
- 难度：中等
- 状态：LeetCode 已通过

## 题意

给一个数组 `nums`，`nums[i]` 表示第 `i` 间房子里的金额。

不能偷相邻的两间房子，问最多可以偷到多少钱。

## 我的思路

使用动态规划。

定义：

```text
dp[i] 表示考虑到第 i 间房子时，最多可以偷到的钱。
```

对于第 `i` 间房子，有两种选择：

1. 不偷第 `i` 间，那么结果就是 `dp[i - 1]`。
2. 偷第 `i` 间，那么不能偷第 `i - 1` 间，结果是 `dp[i - 2] + nums[i]`。

所以转移方程：

```c
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i]);
```

初始状态：

```c
dp[0] = nums[0];
dp[1] = max(nums[0], nums[1]);
```

如果只有一间房子，直接返回 `nums[0]`。

## 关键边界

- 只有一间房子，要直接返回 `nums[0]`，避免访问 `nums[1]`。
- 只有两间房子，返回两者最大值。
- 金额全都一样。
- 最优方案可能隔一个偷一个，也可能跳过多个房子。

## 错误记录

- 设置 `dp[1]` 前，要先处理 `numsSize == 1`。
- 这题不能贪心地只看当前房子金额大小，因为是否能偷还受到相邻限制影响。

## 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`，当前使用 `dp` 数组；后续可以优化成两个变量。

## 本地输入格式

```text
n
nums[0] nums[1] ... nums[n-1]
```

样例：

```text
4
1 2 3 1
```

正确输出应该是：

```text
4
```
