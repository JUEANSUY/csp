# 014-lc14-longest-common-prefix

## 题目信息

- 来源：LeetCode 14 Longest Common Prefix
- 链接：https://leetcode.cn/problems/longest-common-prefix/
- 类型：字符串
- 难度：简单
- 状态：LeetCode 已通过

## 题意

给一个字符串数组，找出所有字符串共同拥有的最长前缀。

如果没有公共前缀，返回空字符串 `""`。

## 我的思路

用第一个字符串 `strs[0]` 当作参考答案，从左到右逐个字符检查。

对每个位置 `i`：

- 用所有其他字符串 `strs[j]` 和 `strs[0]` 比较。
- 如果某个字符串在位置 `i` 已经结束，说明公共前缀只能到 `i - 1`。
- 如果某个字符和 `strs[0][i]` 不一样，说明公共前缀也只能到 `i - 1`。

这两种情况都可以直接把：

```c
strs[0][i] = '\0';
```

这样就把第一个字符串截断成了公共前缀，然后返回 `strs[0]`。

## 关键边界

- 没有公共前缀，例如 `dog racecar car`，应该返回空字符串。
- 只有一个字符串，直接返回它本身。
- 某个字符串本身就是公共前缀，例如 `ab abc abcd`。
- 字符串长度不一样时，要先判断是否遇到 `'\0'`。

## 错误记录

- 不能返回函数内部新建的局部数组，因为函数结束后局部数组会失效。
- 遇到字符不一样时，不能直接返回完整的 `strs[0]`，要先写 `strs[0][i] = '\0'` 截断。
- 如果第一个字符串完整匹配结束，最后应该返回 `strs[0]`，不是返回 `""`。

## 复杂度

- 时间复杂度：`O(S)`，其中 `S` 是所有被比较字符的总数，最坏可以看作 `O(n * m)`。
- 空间复杂度：`O(1)`，直接修改第一个字符串，没有额外开数组。

## 本地输入格式

```text
n
strs[0]
strs[1]
...
strs[n-1]
```

样例：

```text
3
flower
flow
flight
```

正确输出应该是：

```text
fl
```
