# 028-lc739-daily-temperatures

## 题目信息

- 来源：LeetCode 739 Daily Temperatures
- 链接：https://leetcode.cn/problems/daily-temperatures/
- 类型：单调栈
- 难度：中等
- 状态：LeetCode 已通过

## 题意

给一个温度数组 `temperatures`，返回一个数组 `answer`。

`answer[i]` 表示从第 `i` 天开始，还要等多少天才会遇到更高温度。

如果后面没有更高温度，`answer[i] = 0`。

## 我的思路

使用单调栈。

栈里存的是下标，不是温度值。

栈里保存的是：

```text
还没等到更高温度的天数下标
```

从左到右遍历每一天 `i`：

1. 如果当前温度 `temperatures[i]` 比栈顶那一天更高，说明栈顶那一天终于等到了更高温度。
2. 弹出栈顶下标 `idx`。
3. 计算 `answer[idx] = i - idx`。
4. 继续检查新的栈顶，直到栈为空或当前温度不再更高。
5. 最后把当前下标 `i` 入栈。

## 栈写法

用数组模拟栈：

```c
int stack[MAXN];
int top = -1;
```

`top = -1` 表示空栈。

入栈：

```c
top++;
stack[top] = i;
```

出栈：

```c
int idx = stack[top];
top--;
```

每一天最后都要入栈，因为当前这一天也需要等未来更高温度。

## 关键边界

- 温度一直下降，答案全是 0。
- 温度一直上升，每天都等 1 天。
- 有相同温度，相同不算更高。
- 最后一天答案一定是 0。

## 错误记录

- 栈顶初始值应该是 `-1`，不要从 `1` 开始。
- 第 0 天也要正常入栈，所以循环从 `i = 0` 开始。
- 当前下标每轮最后都要入栈，不能只在某个条件下入栈。
- 条件要用 `>`，相同温度不算更高，不能用 `>=`。

## 复杂度

- 时间复杂度：`O(n)`，每个下标最多入栈一次、出栈一次。
- 空间复杂度：`O(n)`，栈和返回数组。

## 本地输入格式

```text
n
temperatures[0] temperatures[1] ... temperatures[n-1]
```

样例：

```text
8
73 74 75 71 69 72 76 73
```

正确输出应该是：

```text
1 1 4 2 1 1 0 0
```
