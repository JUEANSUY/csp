## 题意

给定一个数组 `nums` 和一个值 `val`，原地删除数组中所有等于 `val` 的元素，并返回删除后的新长度。新长度之后的元素不用管。

## 我的思路

使用保序双指针：

- `j` 负责从前往后遍历原数组。
- `i` 表示新数组下一个可以写入的位置。
- 如果 `nums[j] != val`，说明这个元素要保留，就写到 `nums[i]`，然后 `i++`。
- 如果 `nums[j] == val`，说明这个元素要删除，直接跳过。
- 遍历结束后，`i` 就是新数组长度。

这个方法会保留剩余元素的原相对顺序，写起来比较稳。

## 另一种解法

题目不要求保留元素顺序，所以也可以使用首尾交换法：

```c
int removeElement(int *nums, int numsSize, int val) {
    int i = 0;
    int n = numsSize;

    while (i < n) {
        if (nums[i] == val) {
            nums[i] = nums[n - 1];
            n--;
        } else {
            i++;
        }
    }

    return n;
}
```

这个写法的关键点是：如果 `nums[i] == val`，把末尾元素换到当前位置之后，`i` 不能立刻加一，因为换过来的新元素还没有检查。

考试或练习时，优先使用自己更稳的写法。

## 关键边界

- 数组中没有 `val`：返回原长度。
- 数组中全是 `val`：返回 `0`。
- `val` 出现在开头：能正确跳过。
- `val` 出现在结尾：能正确跳过。
- `val` 连续出现多次：能全部跳过。
- 单元素数组：能正确处理。

## 复盘

这题的核心不是“真正删除数组元素”，而是把要保留的元素放到数组前面，并返回新的有效长度。LeetCode 只检查前 `len` 个元素，所以 `len` 后面的内容不用处理。
