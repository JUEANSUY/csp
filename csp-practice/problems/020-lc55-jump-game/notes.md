# 020-lc55-jump-game

## 题目信息

- 来源：LeetCode 55 Jump Game
- 链接：https://leetcode.cn/problems/jump-game/
- 类型：贪心
- 难度：中等
- 状态：LeetCode 已通过

## 题意

给一个非负整数数组 `nums`，`nums[i]` 表示站在下标 `i` 时，最多可以向右跳多少步。

一开始站在下标 `0`，判断能不能到达最后一个下标。

## 我的思路

维护一个变量，表示当前最远能到达的位置。

当前代码里用的是：

```c
int max = nums[0];
```

它表示从已经能到达的位置出发，目前最远可以到哪里。

遍历时，只遍历 `i <= max` 的位置，因为超过 `max` 的位置当前根本到不了。

每到一个可达位置 `i`，就尝试更新最远距离：

```c
max = max > nums[i] + i ? max : nums[i] + i;
```

如果：

```c
max >= numsSize - 1
```

说明已经能到达最后一个下标，可以直接返回 `true`。

如果循环结束还没有到达最后一个下标，说明被某个位置卡住了，返回 `false`。

## 贪心点

这题的贪心策略是：

```text
每到一个可达位置，就尽量更新“当前能到的最远位置”。
```

不需要关心具体怎么跳，只需要关心可达范围能不能覆盖到最后。

## 关键边界

- 只有一个元素，例如 `[0]`，答案是 `true`。
- 中间遇到 `0`，但前面可以跳过去。
- 中间遇到 `0`，而且前面跳不过去。
- 一开始就是 `0`，但数组长度大于 1，答案是 `false`。
- 最远可达位置超过最后下标时，可以提前返回 `true`。

## 错误记录

- 不要只看当前 `nums[i]` 是否为 `0`，要看当前最远可达位置能不能跨过它。
- 这题不需要真的模拟每一种跳法，维护最远可达位置即可。

## 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 本地输入格式

```text
n
nums[0] nums[1] ... nums[n-1]
```

样例：

```text
5
2 3 1 1 4
```

正确输出应该是：

```text
true
```
