# 024-lc994-rotting-oranges

## 题目信息

- 来源：LeetCode 994 Rotting Oranges
- 链接：https://leetcode.cn/problems/rotting-oranges/
- 类型：BFS
- 难度：中等
- 状态：LeetCode 已通过

## 题意

给一个二维网格：

- `0` 表示空格。
- `1` 表示新鲜橘子。
- `2` 表示腐烂橘子。

每过一分钟，腐烂橘子会让上下左右相邻的新鲜橘子腐烂。求让所有新鲜橘子都腐烂所需的最少分钟数。

如果最后仍然有新鲜橘子不能腐烂，返回 `-1`。

## 我的思路

使用多源 BFS。

先扫描整个网格：

- 遇到 `1`，说明有一个新鲜橘子，`fresh++`。
- 遇到 `2`，说明这是一个初始腐烂源，把它的位置入队。

然后按层 BFS：

```text
队列里的当前一层 = 当前这一分钟会向外扩散的腐烂橘子
```

每一轮：

1. 记录当前层大小 `size = rear - front`。
2. 只处理这一层的 `size` 个腐烂橘子。
3. 如果它们上下左右有新鲜橘子，就改成 `2`，`fresh--`，并入队。
4. 当前层处理完，说明过了一分钟，`minutes++`。

循环结束后：

- 如果 `fresh == 0`，返回 `minutes`。
- 否则说明还有新鲜橘子永远不会腐烂，返回 `-1`。

## 队列写法

用两个数组分别存行和列：

```c
int queueR[MAXR * MAXC];
int queueC[MAXR * MAXC];
int front;
int rear;
```

`front` 指向下一个要弹出的元素，`rear` 指向下一个要插入的位置。

入队：

```c
queueR[rear] = r;
queueC[rear] = c;
rear++;
```

出队：

```c
int r = queueR[front];
int c = queueC[front];
front++;
```

## 关键边界

- 一开始没有新鲜橘子，答案是 0。
- 没有腐烂橘子，但有新鲜橘子，答案是 -1。
- 有新鲜橘子被空格隔开，永远不会腐烂。
- 多个腐烂橘子同时向外扩散，所以要把所有初始腐烂橘子一起入队。
- 只有一行或一列。

## 错误记录

- `empty` 是函数，调用时要写 `empty()`。
- 当前层大小应该是 `rear - front`，不是 `rear - front + 1`。
- 不能每腐烂一个橘子就 `minutes++`，而是每处理完一层才加一分钟。
- 越界方向要 `continue` 跳过，避免访问非法下标。

## 复杂度

- 时间复杂度：`O(m * n)`。
- 空间复杂度：`O(m * n)`，队列最多存下所有格子。

## 本地输入格式

```text
rows cols
grid[0][0] grid[0][1] ...
grid[1][0] grid[1][1] ...
...
```

样例：

```text
3 3
2 1 1
1 1 0
0 1 1
```

正确输出应该是：

```text
4
```
