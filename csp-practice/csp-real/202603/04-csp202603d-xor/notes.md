# CSP202603D 异或

## 题目信息

- 来源：第 41 次 CCF CSP 认证，CSP202603D
- 题目：异或
- 类型：位运算 / 待分析
- 状态：练习中

## 题意

本题围绕异或运算展开，需要根据题目要求计算或维护某种异或结果。

异或常用性质：

- `x ^ x = 0`
- `x ^ 0 = x`
- 异或满足交换律和结合律。
- 区间异或可以用前缀异或：`xor(l, r) = prefix[r] ^ prefix[l - 1]`。

## 思路提示

先判断题目要求的是：

- 单次数组计算。
- 多次区间查询。
- 是否有修改操作。
- 是否要求最大异或、计数或构造。

如果只有静态区间查询，优先考虑前缀异或。

如果有修改和查询，可能需要树状数组、线段树或 Trie。

## 关键边界

- 全部数字相同。
- 有 0。
- 查询单个位置。
- 查询整个区间。
- 数据范围大时，注意 O(nq) 是否会超时。
