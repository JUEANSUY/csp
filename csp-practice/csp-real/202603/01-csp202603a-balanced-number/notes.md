# CSP202603A 平衡数

## 题目信息

- 来源：第 41 次 CCF CSP 认证，CSP202603A
- 题目：平衡数
- 链接：https://oj.shumeng.tech/p/CSP202603A
- 类型：位运算 / 模拟
- 状态：OJ 100 分

## 题意

给定 `n` 个正整数。

如果一个正整数的二进制表示中，`0` 的个数和 `1` 的个数相等，那么它就是平衡数。

二进制表示不考虑前导零。

例如：

- `2` 的二进制是 `10`，有一个 `1` 和一个 `0`，是平衡数。
- `5` 的二进制是 `101`，有两个 `1` 和一个 `0`，不是平衡数。
- `9` 的二进制是 `1001`，有两个 `1` 和两个 `0`，是平衡数。

目标：统计输入的 `n` 个数里有多少个平衡数。

## 思路提示

可以对每个数单独判断：

- 当 `x > 0` 时，不断取 `x % 2` 或 `x & 1` 得到最低二进制位。
- 如果这一位是 `1`，`cnt1++`。
- 如果这一位是 `0`，`cnt0++`。
- 然后让 `x /= 2` 或 `x >>= 1`。
- 最后判断 `cnt0 == cnt1`。

注意：题目不考虑前导零，所以只处理 `x` 本身的二进制位。

## 关键边界

- `a = 1`，二进制是 `1`，不是平衡数。
- `a = 2`，二进制是 `10`，是平衡数。
- `a = 3`，二进制是 `11`，不是平衡数。
- `a = 12`，二进制是 `1100`，是平衡数。
- 最大 `a` 可到 `10^9`，但二进制位数很少，逐位处理可以通过。

## 错误记录

- 调试时重点观察 `x % 2` 得到的当前二进制位，以及 `x /= 2` 是否正确去掉最低位。
- `0` 和 `1` 的计数只统计数字自身的二进制表示，不统计前导零。

## 复杂度

- 时间复杂度：O(n log A)，其中 `A` 是输入数字的最大值。每个数只需要按二进制位数检查。
- 空间复杂度：O(1)。

## 测试记录

- 本地样例输出：`2`。
- 曙梦 OJ：100 分。

## 本地输入格式

```text
n
a1 a2 ... an
```

样例：

```text
3
2 5 9
```

正确输出：

```text
2
```
