# CSP202603C 进程通信

## 题目信息

- 来源：第 41 次 CCF CSP 认证，CSP202603C
- 题目：进程通信
- 类型：待分析
- 状态：练习中

## 题意

本题围绕进程之间的通信规则展开，需要根据题目描述模拟或判断通信过程。

建议先把题目中的对象拆清楚：

- 有哪些进程。
- 一次通信操作包含哪些信息。
- 通信成功或失败的条件是什么。
- 输出是每次操作的结果，还是最终状态。

## 思路提示

这类题通常难点不在某个高级算法，而在把规则实现准确。

建议先做：

1. 画出样例过程。
2. 明确每个进程需要维护哪些状态。
3. 如果有等待关系，考虑队列或图。
4. 如果有配对关系，考虑哈希表、数组或队列记录待匹配事件。

## 关键边界

- 一个进程多次发送或接收。
- 操作无法匹配。
- 多个进程形成等待链。
- 输入规模较大时，避免每次操作都全量扫描。
