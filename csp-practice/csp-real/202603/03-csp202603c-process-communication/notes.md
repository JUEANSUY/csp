# CSP202603C 进程通信

## 题目信息

- 来源：第 41 次 CCF CSP 认证，CSP202603C
- 题目：进程通信
- 类型：模拟 / 内存区间管理 / 排序
- 状态：OJ 100 分

## 题意

有 `n` 个进程，支持三种操作：

- `new p L`：给进程 `p` 新建一个长度为 `L` 的队列，输出分配到的起始地址。
- `send p`：进程 `p` 对自己的所有队列各发送一个对象，输出这些对象存放地址之和。
- `delete p i`：删除进程 `p` 的第 `i` 个队列，不输出。

`new` 分配地址时使用最优适应原则：在所有能放下长度 `L` 的空闲连续区间里，选择长度最短的；如果长度相同，选择左端点最小的。

## 思路

每个队列需要维护三个信息：

- `left`：队列起始地址。
- `len`：队列长度。
- `last`：上一次 `send` 存放的位置，初始为 `-1`。

用 `queues[p][i]` 表示进程 `p` 的第 `i` 个队列，`cnt[p]` 表示进程 `p` 当前有多少个队列。

处理 `new` 时：

1. 收集所有还存在的队列区间 `[left, left + len - 1]`。
2. 按左端点从小到大排序。
3. 扫描地址 `0` 到第一个区间前、相邻区间之间、最后一个区间之后的空闲位置。
4. 找到符合最优适应原则的起始地址。

处理 `send` 时，遍历进程 `p` 的所有队列：

- 如果 `last == -1`，本次发送放到 `left`。
- 否则 `last++`。
- 如果超过队列末尾，就回到 `left`。

处理 `delete` 时，把删除位置后面的队列整体前移一格，并让 `cnt[p]--`。

## 关键边界

- 队列编号从 `1` 开始，遍历时要写 `i <= cnt[p]`，不能漏掉最后一个队列。
- `send` 时队列内地址要循环回到 `left`。
- 删除队列后，释放出来的地址要能被后续 `new` 复用。
- 最前面的空闲区间 `0` 到 `seg[0].left - 1` 不能漏掉。
- 地址和答案可能较大，使用 `long long`。

## 错误记录

- `#define MAXN 1001;` 多写了分号，导致数组声明展开错误。
- 结构体类型要先 `typedef`，再定义该类型的数组。
- `printf("%lld\n", &nextAddr)` 输出了变量地址，应该输出变量值。
- 收集队列区间时一开始写成 `i < cnt[p]`，会漏掉最后一个队列。

## 复杂度

- `new`：设当前存在 `m` 个队列，收集和排序为 `O(m log m)`。
- `send`：设进程 `p` 有 `k` 个队列，时间复杂度 `O(k)`。
- `delete`：设进程 `p` 有 `k` 个队列，最坏时间复杂度 `O(k)`。
- 空间复杂度：`O(m)`，用于保存当前所有占用区间。

## 复盘

这题不是高级算法难，而是规则多、状态容易写错。比较好的做法是先把操作拆成 `new/send/delete` 三块，再把每个队列需要维护的信息确定下来。最优适应原则可以转化成“收集已占用区间、排序、扫描空隙”。
