# CSP202603B 机器人项目管理

## 题目信息

- 来源：第 41 次 CCF CSP 认证，CSP202603B
- 题目：机器人项目管理
- 链接：https://oj.shumeng.tech/p/CSP202603B
- 类型：0/1 背包 + 分数背包 / 贪心
- 状态：OJ 100 分

## 题意

有 `n` 个任务，最多可以使用 `m` 杯咖啡来减少总耗时。

每个任务有四个参数：

- `o`：任务类型。
- `t`：任务原本耗时。
- `a`：如果给这个任务使用咖啡，最多需要或可以使用的咖啡量。
- `b`：最多可以减少的耗时。

两类任务不同：

- `o == 1`：普通任务。只能不使用咖啡，或者一次性使用 `a` 杯，减少 `b` 时间。
- `o == 0`：灵活任务。可以使用 `0` 到 `a` 杯之间的任意实数杯咖啡，收益按比例计算。

目标是让最终总耗时最小。

可以先算所有任务原始总耗时 `sum`，再最大化“能减少的时间”。

最终答案：

```text
sum - 最大减少时间
```

## 解题思路

普通任务是 0/1 背包：

```text
dp[j] = 普通任务一共使用 j 杯咖啡时，最多能减少多少时间
```

对于每个 `o == 1` 的任务：

```c
for (int j = m; j >= a[i]; j--) {
    dp[j] = max(dp[j], dp[j - a[i]] + b[i]);
}
```

这里要从大到小枚举 `j`，因为每个普通任务最多只能选一次。

灵活任务是分数背包：

- 计算性价比 `b / a`。
- 按性价比从大到小排序。
- 剩余咖啡优先给性价比最高的灵活任务。
- 如果剩余咖啡不够拿满某个任务，就按比例拿一部分收益。

最后枚举普通任务用了多少咖啡：

```text
普通任务用 j 杯
灵活任务还能用 m - j 杯
总减少 = dp[j] + flexReduce(m - j)
```

取最大总减少时间。

## 关键边界

- 全部都是普通任务。
- 全部都是灵活任务。
- 咖啡数 `m = 0`。
- 普通任务刚好用完所有咖啡，所以枚举时要包含 `j == m`。
- 灵活任务可能产生小数收益，答案要用 `double`。
- 输出需要满足误差要求，建议使用 `printf("%.6f\n", ans)`。

## 错误记录

- 读入任务时循环次数应该是 `n`，不是咖啡总量 `m`。
- 0/1 背包转移要用 `dp[j - a[i]] + b[i]`，不是固定用 `dp[m - a[i]]`。
- `qsort` 只需要调用一次，不需要放在循环里重复排序。
- 最大减少时间需要用 `double`，否则灵活任务的小数收益会丢失。
- 枚举普通任务用量时要写 `j <= m`，不能漏掉刚好用完咖啡的情况。
- `getFlexReduce()` 不要在同一个判断里重复调用，可以先存到临时变量里。

## 复杂度

- 时间复杂度：O(nm + k log k + mk)，其中 `k` 是灵活任务数量。当前写法每次枚举 `j` 都重新贪心计算灵活任务收益。
- 空间复杂度：O(n + m)。
