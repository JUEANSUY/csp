## 练习顺序

先从 A 题开始，目标不是立刻追求速度，而是完整练习：

1. 读懂题意。
2. 看清输入输出和数据范围。
3. 写本地 `main()`。
4. 用样例和自造样例测试。
5. 记录错误和复杂度。
