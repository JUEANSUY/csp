# CSP202509C HTTP 头信息

## 题目信息

- 来源：CSP202509C
- 题目：HTTP 头信息
- 链接：https://oj.shumeng.tech/p/CSP202509C
- 类型：模拟 / 字符串处理 / Huffman 解码 / 动态表
- 状态：未开始

## 读题记录

- 目标是解码一系列 HPACK 风格的 HTTP 头信息指令。
- 需要维护静态表和动态表。
- 字符串可能是普通字符串，也可能是 Huffman 编码字符串。

## 输入输出

- 输入静态表大小、动态表容量、静态表内容、Huffman 树表示和若干指令。
- 输出每条指令解码后的 `key: value`。

## 思路

- 先实现表格引用和普通字符串，拿部分分。
- 再处理字面量并索引 / 不索引，以及动态表插入和淘汰。
- 最后处理 Huffman 树恢复和十六进制编码解码。

## 关键边界

- 动态表新条目插入最前面，超出容量删除最后一个。
- 静态表编号从 `1` 开始，动态表编号接在静态表之后。
- 普通字符串以 `HH` 开头时要去掉一个 `H`。
- Huffman 编码最后一个字节表示补零个数。
