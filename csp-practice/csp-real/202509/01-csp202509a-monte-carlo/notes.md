# CSP202509A 蒙特卡洛

## 题目信息

- 来源：CSP202509A
- 题目：蒙特卡洛
- 链接：https://oj.shumeng.tech/p/CSP202509A
- 类型：数学 / 模拟 / 几何
- 状态：OJ 100 分

## 题意

给定正方形区域内的若干采样点，统计落在圆内的点数，用蒙特卡洛方法估计圆周率。

## 输入输出

- 输入 `n` 和半径 `a`。
- 接着输入 `n` 个点 `(x, y)`。
- 输出估计值 `4 * 圆内点数 / n`。

## 思路

判断点是否在圆内，只需要判断它到原点的距离是否不超过半径。

为了避免 `sqrt` 带来的浮点误差和额外计算，可以直接比较平方：

```c
x * x + y * y <= (double)a * a
```

如果点在圆内，就让计数器加一。最后输出：

```c
4 * cnt / n
```

## 关键边界

- 题目说圆形内包含边界，所以距离刚好等于 `a` 的点也算。
- 判断时用 `<=`，不能用 `<`。
- 可以不用开数组，读一个点处理一个点。

## 错误记录

- 一开始用 `< a`，会把边界点排除，样例中 `(3, 4)` 半径为 `5` 应该算在圆内。
- 后来改成平方比较，避免使用 `sqrt`。

## 复杂度

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 复盘

几何判断里要特别注意边界是否包含。能比较平方时，通常不用开根号。
