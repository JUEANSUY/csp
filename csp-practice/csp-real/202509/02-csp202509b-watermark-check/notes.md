# CSP202509B 水印检查

## 题目信息

- 来源：CSP202509B
- 题目：水印检查
- 链接：https://oj.shumeng.tech/p/CSP202509B
- 类型：矩阵匹配 / 阈值区间 / 模拟
- 状态：OJ 100 分

## 题意

给定一张灰度矩阵和灰度上限 `L`，判断哪些阈值 `k` 能在图中检测出固定的 `CSP` 水印。

规则是：

- 灰度值 `>= k` 的位置看作白色。
- 灰度值 `< k` 的位置看作黑色。
- 需要输出所有可行的 `k`。

## 输入输出

- 输入 `n, L`。
- 接着输入 `n * n` 的灰度矩阵。
- 输出所有可以检测出水印的阈值 `k`，每行一个。

## 思路

水印是固定的 `5 * 9` 矩阵。枚举水印左上角 `(x, y)`，检查这个 `5 * 9` 子矩阵能对应哪些 `k`。

暴力做法是枚举每个 `k`，再枚举每个位置，复杂度较高，只能拿部分分。

更优做法是对每个子矩阵直接求出可行的 `k` 区间：

- 如果水印位置是白色，需要 `val >= k`，所以 `k <= val`。
- 如果水印位置是黑色，需要 `val < k`，所以 `k >= val + 1`。

因此：

```text
low = 所有黑色位置 val + 1 的最大值
high = 所有白色位置 val 的最小值
```

如果 `low <= high`，说明 `[low, high]` 里的所有 `k` 都可行。

## 关键边界

- 水印大小固定为 `5 * 9`。
- 枚举左上角时要满足 `x + 5 <= n`、`y + 9 <= n`。
- `k` 只输出 `[0, L - 1]` 范围内的值。
- 全局数组大小不能用运行时读入的 `L`，所以 `ok` 开最大范围。

## 错误记录

- 二维数组传参时应传 `a`，不能写成 `a[n][n]`。
- `int ok[L]` 不能定义在全局，因为 `L` 是运行时才读入的。
- 暴力枚举 `k` 的写法只能拿 80 分，满分需要按子矩阵直接求可行区间。

## 复杂度

- 当前写法中，枚举每个子矩阵并标记 `[low, high]`，复杂度约为 `O(n^2 * 45 + 区间总长度)`。
- 空间复杂度：`O(L + n^2)`。

## 复盘

当题目要求输出一批可行参数时，不一定要逐个参数试。可以反过来从一个匹配位置推导出“哪些参数都可行”，把单点枚举变成区间标记。
