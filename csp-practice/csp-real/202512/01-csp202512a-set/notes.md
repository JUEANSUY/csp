# CSP202512A 集合

## 题目信息

- 来源：CSP202512A
- 题目：集合
- 链接：https://oj.shumeng.tech/p/CSP202512A
- 类型：集合判断 / 位运算 / 模拟
- 状态：OJ 100 分

## 题意

给定 `n` 个元素的权值 `a_i`，以及 `m` 组集合 `S_i` 和 `T_i`。

小 C 用集合中元素权值的异或和来判断两个集合是否相等。本题要判断：对于每一组 `S_i` 和 `T_i`，小 C 的判断结果是否正确。

## 输入输出

- 输入先给 `n, m`。
- 接着输入 `n` 个权值 `a_i`。
- 然后输入全部 `S_i`。
- 最后输入全部 `T_i`。
- 对每一组询问，输出 `correct` 或 `wrong`。

## 思路

真正需要比较的是两个结果是否一致：

- 真实集合是否相等。
- 两个集合的异或和是否相等。

如果这两个判断结果一样，说明小 C 这次判断正确，输出 `correct`；否则输出 `wrong`。

读入集合时顺手计算异或和：

```c
xorsum ^= a[element];
```

判断真实集合是否相等时，先比较大小，再逐个比较集合元素。

## 关键边界

- 两个集合不相等，但异或和相等：小 C 会误判，应输出 `wrong`。
- 两个集合相等，异或和一定相等：输出 `correct`。
- 集合大小不同，真实集合一定不相等。
- 输入是先给所有 `S_i`，再给所有 `T_i`，不是一组一组交替给。

## 错误记录

- `scanf("%lld", a[i])` 少了 `&`，应写成 `scanf("%lld", &a[i])`。
- 一开始只判断“大小相等且异或和相等”，这不是题目要问的内容。
- 函数名 `askforcorrect` 调用时拼成了 `askforcorret`，导致链接错误。

## 复杂度

- 时间复杂度：`O(所有集合元素个数)`。
- 空间复杂度：`O(mk)`，保存每个集合的元素和异或和。

## 复盘

这题的关键不是异或本身，而是读懂“判断方法是否正确”。要先分清楚“真实答案”和“小 C 的判断答案”，再比较这两个答案是否一致。
