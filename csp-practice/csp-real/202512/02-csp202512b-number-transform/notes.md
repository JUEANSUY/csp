# CSP202512B 数字变换

## 题目信息

- 来源：CSP202512B
- 题目：数字变换
- 链接：https://oj.shumeng.tech/p/CSP202512B
- 类型：位运算 / 模拟 / 反查表
- 状态：OJ 100 分

## 题意

题目定义了一个 9 位整数上的变换。每次变换会根据参数 `k`，把一个数拆成三段 3 位二进制，再重新组合。

给定若干个变换后的结果，要求输出它们各自对应的原始输入。

## 输入输出

- 输入 `n, m`。
- 接着输入 `m` 个变换参数 `k_i`。
- 再输入 `n` 个变换后的结果 `a_i`。
- 对每个 `a_i`，输出它对应的原始输入。

## 思路

关键观察：数的范围只有 9 位，也就是 `0 ~ 511`，一共只有 512 种可能。

所以不用尝试倒推公式。直接枚举所有原始输入：

1. 对每个 `origin` 从 `0` 到 `511`。
2. 让它依次经过 `m` 次变换。
3. 得到最终结果 `x`。
4. 记录 `ans[x] = origin`。

之后每读到一个输出值 `a_i`，直接输出 `ans[a_i]`。

单次变换里，把 9 位拆成三段：

```c
int a = (x >> 6) & 7;
int b = (x >> 3) & 7;
int c = x & 7;
```

其中 `7` 的二进制是 `111`，所以 `& 7` 表示取低 3 位。

## 关键边界

- 输入空间很小，只有 512，不需要倒推。
- `mod 2^3` 就是 `% 8`。
- `^` 在 C 语言中就是按位异或。
- 输出时注意空格格式。

## 错误记录

- 一开始题意容易误读成“要从结果反向推公式”。
- 实际更简单的做法是正向枚举所有原始输入，建立反查表。

## 复杂度

- 预处理时间复杂度：`O(512 * m)`。
- 回答时间复杂度：`O(n)`。
- 空间复杂度：`O(512 + n + m)`。

## 复盘

遇到复杂变换题时，先看值域大小。如果状态空间很小，可以优先考虑枚举所有状态，建立“结果到原始值”的反查表。
