# CSP202512D C 形阵

## 题目信息

- 来源：CSP202512D
- 题目：C 形阵
- 链接：https://oj.shumeng.tech/p/CSP202512D
- 类型：数论 / 积性函数 / 筛法 / 组合数学 / 容斥
- 状态：未开始

## 读题记录

- 题目定义满足若干乘积关系的 `C` 形阵。
- 需要统计大小不超过 `n` 的所有 C 形阵价值总和。
- `op = 0` 统计所有 C 形阵，`op = 1` 统计完美 C 形阵。

## 输入输出

- 输入一行 `op n`。
- 输出价值总和，对 `998244353` 取模。

## 思路

- 小数据可以枚举 `A,B,C,D,E,F,G` 验证关系。
- 满数据需要数论推导，题面标签包含积性函数、筛法、组合数学和容斥。
- 先从 `B A = C B`、`F E = G F`、三个乘积相等这些关系化简。

## 关键边界

- `op = 0` 和 `op = 1` 要求不同。
- 完美 C 形阵要求 7 个数中恰好 6 个互不相同。
- `n` 可到 `10^7`，不能高维枚举。
