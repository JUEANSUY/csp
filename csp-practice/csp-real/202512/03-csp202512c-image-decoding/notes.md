# CSP202512C 图片解码

## 题目信息

- 来源：CSP202512C
- 题目：图片解码
- 链接：https://oj.shumeng.tech/p/CSP202512C
- 类型：模拟 / 矩阵变换 / 懒旋转
- 状态：OJ 100 分

## 题意

给定加密后的正方形图片和一串操作，要求倒序解密，恢复原始图片。

操作主要有两类：

- 局部旋转加密：局部 `L * L` 子矩阵顺时针旋转，随后整张图逆时针旋转若干次。
- 局部翻转加密：指定矩形区域上下或左右翻转。

解密时需要倒着处理操作，并把每个操作反过来执行。

## 输入输出

- 输入加密后的 `Z * Z` 图片。
- 输入操作序列。
- 输出原始图片的行数、列数和图片内容。

## 思路

先倒序遍历操作序列。

对于翻转操作，因为翻转本身可逆，所以解密时仍然做同方向翻转。

对于旋转操作：

- 加密时整图逆时针旋转，解密时整图顺时针旋转。
- 加密时局部顺时针旋转，解密时局部逆时针旋转。

最开始直接真实旋转整张 `Z * Z` 图片，会在大数据下超时。优化方法是用 `rot` 懒标记记录当前整图顺时针旋转了几次，不真的搬动整张图。

之后所有访问都经过坐标映射：

```c
getCell(a, x, y)
setCell(a, x, y, value)
swapCell(a, x1, y1, x2, y2)
```

这样整图旋转只需要：

```c
rot = (rot + r) % 4;
```

局部旋转和翻转的范围很小，仍然可以真实交换对应格子。

## 关键边界

- 整图旋转不能每次真实做 `O(Z^2)`，否则会 TLE。
- 局部子矩阵转置要用相对坐标 `(u + i, v + j)`，不能默认 `u == v`。
- `d` 是角度，要用 `d / 90` 得到旋转次数。
- 输出时也要通过 `getCell`，不能直接访问原数组。
- 最终输出需要先输出原图行列数。

## 错误记录

- 一开始遗漏输出原图尺寸，导致标准答案比用户输出更长。
- 一开始每次真实旋转整张图，满数据 TLE。
- 局部转置最初直接用原数组下标，`u != v` 时会错。
- 调用二维数组函数时曾写成 `a[z][z]`，实际应传 `a`。

## 复杂度

- 整图旋转：`O(1)`，只更新 `rot`。
- 局部旋转/翻转：与局部区域大小有关。
- 总体复杂度：约为所有局部操作面积之和，加上最后输出面积。
- 空间复杂度：`O(Z^2)`。

## 复盘

这题的突破点是把“整图旋转”从真实操作改成懒标记。只要所有读写都统一走坐标映射，整图状态就可以不移动数组本身。
