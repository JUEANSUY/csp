# CSP202512E 数据抢修

## 题目信息

- 来源：CSP202512E
- 题目：数据抢修
- 链接：https://oj.shumeng.tech/p/CSP202512E
- 类型：动态规划 / 状态压缩 / 图结构 / 网络流 / 01Trie
- 状态：未开始

## 读题记录

- 有多个数据包，每个数据包是一个可重集。
- 一个数据包稳定当且仅当任意两个元素 `x, y` 满足 `x ^ y >= W`。
- 操作包括添加元素、合并数据包、查询当前所有激活数据包维修代价之和。

## 输入输出

- 输入初始数据包、稳定值 `W` 和若干操作。
- 对每个查询操作输出当前总维修代价。

## 思路

- 先理解单个数据包的“维修代价”：把元素划分为若干稳定子数据包，要求子数据包数量最少。
- 小数据可以考虑把冲突关系建图：若 `x ^ y < W`，二者不能放在同一稳定子包。
- 满数据涉及合并、动态维护和高效计算，题面标签包含状态压缩 DP、二分图匹配、网络流、01Trie、树的合并。

## 关键边界

- 数据包可以为空，也可以有重复权值。
- 单元素数据包一定稳定。
- 合并后 `v` 离线，不再参与后续操作。
- 总元素数和操作数可达 `5 * 10^5`，不能每次从头重算。
